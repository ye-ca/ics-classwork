Practice questions
1. Ask the user for their name, include their name in a greeting string and output it.
2. Ask the user for the cost of an item, add tax and display the total to the user in a string like `Your total is $15.67`.
3. Ask the user for their name. Output a message telling them what letter their name starts with and ends with. If their name is `Jeff`, then you would say it starts with `"J"` and ends with `"f"`.
4. Ask the user for a word and output the word excluding the first and last letter. Use a "slice" for this. You can use the builtin function `len()` to give you the length of the word, or use `-1` in the slice.
